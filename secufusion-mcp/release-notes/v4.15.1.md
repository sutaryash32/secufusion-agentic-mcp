## Summary
Patch release on top of 4.15.0: the editor review always uses the model you are logged into, the engines (Anthropic, OpenAI) are only for the `sfn-ci` command line, and the repository no longer stores any secret-shaped test data. No new tools (122 in all). No breaking changes.

## Added
- `SFN_ANTHROPIC_KEY` and `SFN_OPENAI_KEY` as aliases for the providers' own key variables, so a pipeline can map its secret without naming the provider variable.
- A test that the shared judgment code never reads the environment or calls a provider, even when engines are configured.
- Eval fixtures can use `{{S}}` for a credential-shaped value; each build replaces it with a fresh random one.

## Changed
- `judge` (the judgment protocol behind `/sfn-review`) is back to two routes only: the client's model (sampling) or the calling model you are logged into. The engine route added in 4.15.0 is removed.
- `verify_findings` with `mode: cross` accepts another model's answer as `judgment`; without one it says it is not an independent check.
- `/sfn-review` PASS 22 and the guide describe the above.
- Tests build their fake credentials at runtime.
- The pipeline templates pin `secufusion-mcp@4.15.1`.

## Fixed
- A tag `v4.15.0` was created on the 4.13.0 commit before the 4.15.0 pull request was merged. 4.15.1 is the first version that contains this work; the stale tag should be deleted.

## Breaking changes
None. Engines were never required for the editor.

## New tools
None.

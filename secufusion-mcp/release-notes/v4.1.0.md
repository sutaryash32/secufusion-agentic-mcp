## Summary
DNA (what exists) and Project Intelligence (`.mcp/`, why it exists) are presented as one Unified Project Knowledge System, and the Project Intelligence Layer gains a health report, starter templates and a suggestion engine.

## Added
- Unified view: `load_project_knowledge` (and so `/sfn-init`) prints DNA counts beside `.mcp/` entry counts.
- Project Intelligence health report (`get_knowledge_health`): documented versus discovered entities (services, topics, golden rules, domain concepts, platform decisions) with the definition printed, never a score. Anomalies appear as known-exception candidates, outside the coverage line.
- Starter templates per category in `.mcp/templates/`, and opt-in auto-scaffold (`_meta.auto_scaffold_knowledge: true` or `SECUFUSION_AUTO_SCAFFOLD=1`). Scaffolding creates structure only, never knowledge.
- Knowledge suggestion engine (`suggest_project_knowledge`): repeated investigation is detected and suggestions cite evidence and give a prefilled `record_project_knowledge` call without a body.
- Tribal-knowledge detection across every agent-facing file (`AGENTS.md`, `CLAUDE.md`, `.agents/`, skill-bundled copies).

## Changed
- Any agent file over 250 lines gets a warning that project knowledge belongs in `.mcp/`.
- `scan_repository_stack` inspects service folders, not only the workspace root.

## Fixed
- Release notes now read the migrations format this MCP writes (`microservices`) and say "Not compared" instead of claiming no change.
- Scans no longer destroy the previous `.secufusion-migrations.json`: a timestamped backup is kept and line endings preserved.
- The server reported version `1.0.0` to MCP clients; it now reports the package version.
- The repository's `.agents` persona files are re-aligned with the shipped copies.

## Breaking changes
None.

## New tools
`get_knowledge_health`, `suggest_project_knowledge`.
